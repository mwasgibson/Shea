# Shea Core AI Assistant

A Jarvis-style personal AI assistant built with Python, voice interaction, and modular automation features.

## Overview

Shea Core is designed to understand voice commands, automate tasks, and provide intelligent responses using a modular architecture.

## Features

- Voice command recognition.
- Speech-to-text interaction.
- Text-to-speech responses.
- Task automation.
- Modular plugin-based design.
- API integrations for external services.
- Privacy-focused design.

## Tech Stack

- Python
- FastAPI
- Vosk
- NLP libraries
- Speech recognition
- Text-to-speech tools
- REST APIs

## Installation

1. Clone the repository.
```bash
git clone https://github.com/yourusername/shea-core.git
```

2. Create a virtual environment.
```bash
python -m venv venv
```

3. Activate the virtual environment.
```bash
source venv/bin/activate
```

4. Install dependencies.
```bash
pip install -r requirements.txt
```

5. Run the assistant.
```bash
python main.py
```

## Usage

- Launch the assistant.
- Speak a command or type a prompt.
- The assistant processes the input and returns a response.
- Use supported modules for automation tasks.

## Example Commands

- “What’s the weather today?”
